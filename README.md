# couchdb-python

Python SDK for Apache CouchDB 3.x. It comes as two packages, both published together as `couchdb-sdk` on PyPI:

| Package | What it is | Edited by |
|---------|-----------|-----------|
| `couchdb_sdk` | Idiomatic client: dict-like documents, automatic `_rev` tracking, typed errors, conflict retries | hand-written |
| `couchdb_client` | Low-level client generated from [couchdb-openapi](https://github.com/laveresteban/couchdb-openapi) ([API docs](docs/)) | **generated, don't edit** |

## Quick start

```python
from couchdb_sdk import CouchDB, Conflict

with CouchDB("http://localhost:5984", "admin", "password") as couch:
    db = couch.create_database("people")

    db["alice"] = {"age": 30}           # create
    alice = db["alice"]                 # read -> dict with _id/_rev
    alice["age"] = 31
    db.save(alice)                      # update; alice["_rev"] is refreshed

    db.update("alice", lambda d: {**d, "age": d["age"] + 1})  # retries on 409

    db.bulk_save([{"age": a} for a in (20, 40, 50)])
    db.create_index(["age"], name="age-idx")
    older = db.find({"age": {"$gt": 30}}, sort=[{"age": "desc"}]).docs

    db.save_design("stats", {"by_age": {"map": "function(d){ emit(d.age, 1); }", "reduce": "_count"}})
    db.view("stats", "by_age")

    db.put_attachment("alice", "avatar.png", open("avatar.png", "rb").read(), "image/png")
    feed = db.changes(since="0")
    couch.replicate("people", "people_backup", create_target=True)
```

Errors are typed: `NotFound` (also a `KeyError`), `Conflict`, `Unauthorized`,
`Forbidden`, `PreconditionFailed`, all subclasses of `CouchDBError` with
`.status`, `.error` and `.reason`.

Need an endpoint the wrapper doesn't cover? Use the generated client directly:
`couchdb_client.DocumentsApi(couch.client)`.

## Repository layout

```
couchdb_client/        generated; regenerated by couchdb-sdk-generator PRs
couchdb_sdk/           hand-written idiomatic layer
tests/                 pytest: unit + integration (real CouchDB)
conformance/           Gauge step implementations for the shared cross-SDK suite
scripts/conformance.sh runs the shared suite from couchdb-sdk-generator
```

Files the generator must not touch are listed in `.openapi-generator-ignore`.

## Testing

Both suites need a CouchDB server:

```sh
docker run -d --name couchdb -p 5984:5984 -e COUCHDB_USER=admin -e COUCHDB_PASSWORD=password couchdb:3.4
curl -X PUT http://admin:password@localhost:5984/_users

python -m venv .venv && .venv/Scripts/activate      # or: source .venv/bin/activate
pip install -e . -r test-requirements.txt

pytest tests                       # unit + integration
bash scripts/conformance.sh        # Gauge conformance (needs Node; specs from ../couchdb-sdk-generator)
bash scripts/conformance.sh --tags documents        # one area
```

Override the server with `COUCHDB_URL`, `COUCHDB_USER` and `COUCHDB_PASSWORD`.

## Versioning

The package version is the spec's `info.version`, stamped at generation time.
`.generated-from` records the exact spec and generator commits.
